# SakuGIS 0.4.1 / 0.4.1 版本说明

0.4.1 是模型提供商兼容性更新。Qwen 继续作为本机和新安装的默认选项，用户
也可以在统一设置中选择 Kimi K3；只需要完整配置当前所选提供商。

- 新增 Kimi K3 图片与文字输入、`low` / `high` / `max` 推理强度。
- Qwen 与 Kimi 使用不同的 macOS 钥匙串服务，互不覆盖，也不会进入 `.sgd`。
- Kimi K3 使用独立输出预算，避免强制推理耗尽输出后无法生成结构化 JSON。
- 区分未配置 Key、Key 无效或过期、接口无法连接、超时和额度不足。
- 设置保存后从下一次 Agent 分析立即生效，无需重启。
- 设置窗口在浅色模式下使用可滚动内容区，并提高输入框和状态框高度，避免
  小窗口中出现文字裁切或 URL 看似空白。
- 完成分析后可在“修改输入”和“查看结果”之间往返，保留候选、评分、GIS
  结果和地图图层，不会触发额外模型调用。

0.4.1 is a model-provider compatibility update. Qwen remains the default for
existing and new installations. Users can optionally select Kimi K3 and only
the active provider must be fully configured.

- Adds Kimi K3 image/text input and Low, High, or Max reasoning effort.
- Isolates Qwen and Kimi credentials in separate macOS Keychain services.
- Reserves K3 output capacity so mandatory reasoning cannot consume the final
  structured JSON response.
- Distinguishes missing credentials, invalid or expired keys, unreachable
  endpoints, timeouts, and quota/rate-limit failures.
- Applies provider changes to the next Agent run without restarting.
- Makes the light-mode Settings form scrollable and keeps input/status fields
  tall enough to prevent clipped text or apparently blank URLs.
- Adds an Edit Input / View Result round trip that preserves candidates,
  scores, GIS output, and map layers without another model request.
