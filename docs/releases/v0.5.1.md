# SakuGIS 0.5.1 / 0.5.1 版本说明

0.5.1 是模型能力更新，将 SakuGIS 的默认千问模型升级为最新的多模态
`qwen3.8-max`。

- 默认 Qwen 模型由 `qwen3.7-plus` 升级为 `qwen3.8-max`。
- 设置菜单新增 `qwen3.8-flash`，同时保留 `qwen3.7-plus` 和自定义模型 ID。
- 使用 SakuGIS 自身的 OpenAI 兼容客户端验证结构化 JSON 输出。
- 使用真实图片验证视觉输入，模型正确识别图片内容且无需重试。
- 本机已有 Qwen API Key 继续保存在 macOS 钥匙串，不会写入 App、DMG、
  `.sgd` 工程或 Git 仓库。
- 保留 0.5.0 的 QGIS 原生符号、属性表、PDF/PNG 出图和工程复盘能力。
- 修复 macOS Retina 与浅色/深色主题下图层显隐勾选框可能透明或显示异常的
  问题，同时保留 QGIS 原生图层树交互。
- 发布回归覆盖 69 项核心测试、设置、底图、Agent/候选联动、`.sgd` 复盘、
  点线面渲染、属性表以及 A4 PDF/PNG 出图。

## 安装注意事项

- 仅支持 Apple Silicon Mac，需要 macOS 13 或更高版本。
- DMG 包含独立 QGIS LTR 运行时，无需另行安装 QGIS，因此文件较大。
- 当前构建采用 ad-hoc 签名且未经 Apple 公证；首次启动可能需要在 Finder 中
  右键选择“打开”。
- 如果升级前 SakuGIS 正在运行，请退出并重新启动，以加载新的默认模型设置。

---

SakuGIS 0.5.1 upgrades the default Qwen model to the latest multimodal
`qwen3.8-max`.

- Changes the default from `qwen3.7-plus` to `qwen3.8-max`.
- Adds `qwen3.8-flash` to Settings while retaining the previous model and custom
  compatible model IDs.
- Verifies structured JSON output with SakuGIS' own OpenAI-compatible client.
- Verifies real image input and recognition without a retry.
- Keeps existing Qwen credentials in the macOS Keychain; secrets are never
  included in the App, DMG, `.sgd` files, or repository.
- Retains the native QGIS cartography, attribute table, PDF/PNG export, and
  replayable project workflow from 0.5.0.
- Fixes layer visibility checkboxes that could become transparent or render
  incorrectly on macOS Retina displays in light or dark mode while retaining
  QGIS' native layer-tree interactions.
- Covers 69 core tests plus settings, basemaps, Agent/candidate linkage,
  `.sgd` replay, vector rendering, attribute tables, and A4 PDF/PNG export.

The build requires macOS 13 or later on Apple Silicon. It includes QGIS LTR,
uses an ad-hoc signature, and is not Apple-notarized.
