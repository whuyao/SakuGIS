# SakuGIS 0.5.2 / 0.5.2 版本说明

0.5.2 是小窗口与紧凑布局适配更新。

- Agent 工作区支持纵向滚动，窄窗口下不再截断右侧或底部内容。
- “修改输入 / 查看结果”和导出操作固定在 Agent 面板底部，始终可访问。
- 照片操作拆分为自适应布局，计数、API、Brave 与 GIS 状态文字支持换行。
- 设置窗口在较小尺寸下保持内容可滚动，保存与取消按钮固定可见。
- 主窗口最低支持 900×600；设置窗口已在 620×500 下验证。
- 保留浅色/深色模式、中文/英文界面以及标准大窗口布局。
- 发布回归覆盖 69 项核心测试，以及紧凑与标准窗口、设置、Agent 输入/结果
  切换和打包 App 启动验证。

## 安装注意事项

- 仅支持 Apple Silicon Mac，需要 macOS 13 或更高版本。
- DMG 包含独立 QGIS LTR 运行时，无需另行安装 QGIS，因此文件较大。
- 当前构建采用 ad-hoc 签名且未经 Apple 公证；首次启动可能需要在 Finder 中
  右键选择“打开”。

---

SakuGIS 0.5.2 improves compact-window behavior and small-screen usability.

- Makes the Agent workspace vertically scrollable so right-side and bottom
  content is no longer clipped.
- Pins Edit Input / View Result and export actions to the Agent panel footer.
- Reflows photo controls and wraps API, Brave, and GIS status text.
- Keeps Settings content scrollable with Save and Cancel always visible.
- Supports a 900×600 main window and verifies Settings at 620×500.
- Preserves light/dark appearance, bilingual UI, and the standard large layout.
- Covers 69 core tests plus compact/standard window, Settings, Agent mode switch,
  and packaged App launch checks.

The build requires macOS 13 or later on Apple Silicon. It includes QGIS LTR,
uses an ad-hoc signature, and is not Apple-notarized.
