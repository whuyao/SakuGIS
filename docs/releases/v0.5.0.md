# SakuGIS 0.5.0 / 0.5.0 版本说明

0.5.0 是 GIS 制图能力更新，将导入的点、线、面数据从“可查看”提升为可配色、
可检查、可出图并可在 `.sgd` 工程中复盘的制图工作流。

- 点、线、面图层直接使用 QGIS 原生符号系统。
- 支持单一符号、唯一值分类、连续数值分级、规则渲染、色带、多符号层、
  透明度和数据定义属性。
- 连续数值可使用等间距、分位数等 QGIS 分级方法，并检查直方图、类别边界和图例。
- 新增可搜索、排序的矢量属性表；表格选择与地图要素选择联动，可缩放至所选要素。
- 新增 A4 横向 PDF/PNG 专业出图，包含标题栏、分类图例、指北针、比例尺、制图人、
  出图时间、比例、版本、图幅和图层数量。
- 符号系统接入 QGIS 自带的简体中文翻译，并随 SakuGIS 中英文设置切换。
- QGIS 原生渲染器、色带和图例作为 QML 样式随 `.sgd` 工程保存与恢复。
- 增加针对点、线、面、连续分级、属性选择、PDF/PNG 实际导出的 QGIS 运行时回归。

## 安装注意事项

- 仅支持 Apple Silicon Mac，需要 macOS 13 或更高版本。
- DMG 已包含独立 QGIS LTR 运行时，无需另行安装 QGIS，因此文件较大。
- 当前构建采用 ad-hoc 签名且未经 Apple 公证；首次启动可能需要在 Finder 中右键选择“打开”。
- Google XYZ 影像按现有使用策略仅供交互显示，不写入 PDF/PNG 出图。
- Qwen、Kimi、Brave API Key 和 PostGIS 连接信息不会写入 App、DMG、`.sgd` 或 Git 仓库。

SakuGIS 0.5.0 upgrades imported point, line, and polygon data from basic display
to a practical, replayable cartography workflow.

- Replaces the simplified color picker with QGIS' native symbology editor.
- Supports single, categorized, graduated continuous, and rule-based renderers,
  color ramps, multi-layer symbols, transparency, and data-defined properties.
- Adds searchable and sortable attribute tables with map selection and
  zoom-to-selection linkage.
- Adds professional A4 landscape PDF/PNG output with a title block, legend,
  north arrow, scale bar, creator, print time, scale, version, sheet, and layer
  count.
- Keeps QGIS renderer and legend styles replayable in `.sgd` projects.
- Synchronizes native QGIS Simplified Chinese translations with SakuGIS'
  Chinese/English language setting.
- Adds real QGIS runtime regression coverage for geometry styling, numeric
  graduated rendering, attribute selection, and PDF/PNG export.

The build requires macOS 13 or later on Apple Silicon. It includes its own QGIS
LTR runtime, is ad-hoc signed, and is not Apple-notarized. Google XYZ imagery is
interactive-only and excluded from exported maps. Credentials and PostGIS
connection strings are never included in the App, DMG, `.sgd`, or repository.
