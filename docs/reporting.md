# Markdown 定位报告

完成一次 Geo Agents 分析后，可从面板底部或“文件”菜单导出 `.md` 报告。
报告由本地 Python 代码直接从结构化结果生成，不会再次调用千问或网络服务。

报告包含：

1. 查询文本、照片路径和生成时间；
2. Agent 1 的结构化证据与可靠度；
3. 从查询规划出的 OSM/PostGIS 空间约束；
4. 候选坐标、真实地点检索来源、综合评分、GIS 分数、数据覆盖率和候选半径；
5. 每个候选的地名解析分、模型候选分、证据复核分、证据强度、覆盖率校正
   GIS 分和冲突扣分；
6. 每个候选的地点反查、解释、带照片编号的支持证据、矛盾证据和逐项 GIS 检查；
7. 实际模型、地点检索后端、GIS 后端、结论、限制和未校准声明。

报告语言跟随导出时的 SakuGIS 界面语言。Markdown 中的表格分隔符和换行会
自动转义；文件使用 UTF-8，可直接用于 GitHub、GitLab、Obsidian、Typora
或课程作业。

综合评分用于候选之间的探索性排序，不是统计概率。`不可用`表示相应 OSM
或 PostGIS 查询没有返回可用数据，不等同于约束不匹配。
